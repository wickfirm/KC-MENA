## Recommended continuation workflow

1. Run the static reference locally from the repository root:

   ```powershell
   python -m http.server 3001 --directory 'KME File Folder'
   ```

2. Run Next locally (use the printed port; previous instances used 3000 and
   3002):

   ```powershell
   npm run dev
   ```

3. For each reference route, use the exact same desktop viewport for:
   - reference: `http://localhost:3001/<route>/index.html`
   - Next preview: `http://localhost:<port>/<route>`
   - top, each major section, and footer screenshots.

4. Fix measured differences before proceeding to the next route. Validate
   page content is exposed in the appropriate admin editor, then run:

   ```powershell
   node .\node_modules\next\dist\bin\next build
   ```

5. Commit only task files and push `main`; confirm the public Vercel HTML
   contains the corrected content. Do not call it complete based only on a
   Git push.
